# The One-Line Cat Joke That Lands — entry

A program/v1 entry for the make.fun "The One-Line Cat Joke
That Lands" bounty. `main.py` writes one joke to
`/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that variable is set).

The joke:

> My cat called a family meeting by sitting in the suitcase: agenda, one item; decision, also one.

Minutes were not taken; the outcome was never in doubt. See
`CANDIDATES.md` for the full draft list this winner was
picked from.
